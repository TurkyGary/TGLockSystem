# Adding TGLockSystem executables to the system default path
1- copy the file EnvVar.sh to the folder /etc/profile.d/
2- change the file permissions to 666


# Run scripts at boot 
1- copy the folder 'scripts' to the $HOME folder of the default user
2- copy the file 'TGLockSystemON_indicator.service' to /etc/systemd/system folder
3- enable the service at boot by runnig this command ( sudo systemctl enable TGLockSystemON_indicator.service )
4- enable the service at boot by runnig this command ( sudo systemctl enable TGLockSystem_cardDetect.service )


# Make TGLockSystem global system wide
1- append the default profile (~/.profile) with the following line:
export PATH=$PATH:$TGLOCKSYS
2- logout then login again

# Adjust Switch-ON/OFF, RTC hwclock, 
- All configuration in /boot/firmware/config.txt
